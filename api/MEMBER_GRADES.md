# 회원 등급과 관리자 권한

앱에 표시되는 회원 등급은 일반회원, 미니회원, 협력업체 세 가지입니다. 스탭·운영자는 회원 등급으로 노출하지 않고 Django `is_staff`·`is_superuser` 권한으로 관리자 화면 접근을 분리합니다.

- 기본 가입 계정은 일반회원입니다.
- 미니회원은 운영자가 Django 관리자 > 사용자 > 그룹에서 `ILOVEMINI:미니회원` 그룹에 추가합니다. 이 그룹 자체에는 관리자 접근 권한이 없습니다.
- 활성 업체와 활성 `PartnerStaff` 연결이 있는 계정은 협력업체로 표시합니다.
- 업체 담당자 설정에서 `인증기록 발행 권한`과 `예약 관리 권한`을 업체별로 따로 켜야 해당 기능이 열립니다.
- 일반회원·미니회원으로 바꾸려면 운영자가 업체 담당자 연결을 비활성화합니다.

`GET /api/me/grade/`는 인증된 계정의 회원 등급과 업체 ID만 반환합니다. 이 API로 권한을 변경할 수 없습니다.
